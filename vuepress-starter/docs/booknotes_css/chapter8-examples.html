CSS Mastery — Chapter 8 Hacks & Filters

Demo of classic CSS hacks and modern alternatives.

1) Conditional Comments (IE only)

<!--[if IE]><link rel="stylesheet" href="ie.css"><![endif]-->

Modern browsers ignore these, but they were used to deliver IE-specific stylesheets.

2) Child Selector Hack

Box with child selector padding
html > body .child-hack .box { padding: 1rem; }

3) Attribute Selector Hack

Primary Button Plain Button 
a[class^="btn-"] { background:#2563eb; color:#fff; }

4) Star HTML Hack

Width 180px (modern)
* html .star-hack .box { width:140px; }

5) Underscore Hack

Height 50px
.box { height:90px; _height:50px; }

6) Escaped Property Hack

Width 180px
